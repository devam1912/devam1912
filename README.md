## 🚀 Featured Projects

### ⚔️ CodeDraft — Real-Time Competitive Coding Platform

> Create custom programming problems and compete in synchronized **1v1 and 2v2 coding battles**.

CodeDraft combines a Monaco-based coding environment with Socket.IO-powered room state, teammate code synchronization, live progress, countdowns, submissions, and results. Judge0 is the primary execution engine, backed by controlled local runtimes for supported languages.

**Engineering highlights**

- Live 1v1 and 2v2 battles with synchronized teammate code
- User-created problems, visible examples, and hidden test cases
- Atomic winner selection for concurrent submissions
- Judge0-first execution with controlled JavaScript, Python, C, and C++ fallback
- ELO ratings, leaderboards, profiles, match history, invitations, and notifications
- JWT authentication with token blacklisting and a Dockerized backend
- Designed for future horizontal scaling with Redis, distributed limits, queues, and dedicated workers

`React 19` `Vite` `Tailwind CSS` `Monaco Editor` `Socket.IO` `Node.js` `Express` `MongoDB` `Judge0` `JWT` `Docker`

### 🛠️ Fixate — Agentic AI Code Repair & Verification

> An agentic repair pipeline that finds failures, generates focused patches, verifies them in isolation, and opens GitHub pull requests.

Fixate goes beyond unverified code generation. It combines multi-agent orchestration, AST-aware root-cause localization, repository-scoped RAG, bounded repair retries, isolated test execution, safety checks, and human approval.

**Engineering highlights**

- Five-stage pipeline for localization, retrieval, patching, verification, and safety assessment
- AST-aware chunks and repository-isolated ChromaDB vector indexes
- Deterministic verification for Python, JavaScript/TypeScript, and C++ workflows
- Disposable, resource-limited Docker environments for patch attempts
- Automated GitHub fork, branch, commit, push, and pull-request flow
- Secret redaction, audit events, seven-day workspace retention, and risk controls
- Live pipeline telemetry over Server-Sent Events with dependency-graph and diff views

`Python` `FastAPI` `Pydantic` `React` `TypeScript` `ChromaDB` `NetworkX` `Docker` `GitHub API` `SSE` `RAG`

### 🍱 Tiffins By Naari — Food-Tech Marketplace

> A team-built marketplace connecting customers with home-based tiffin providers, enhanced by personalized food recommendations.

The platform supports customers, providers, and administrators through separate role-based workflows. Its modular Node.js backend works with a standalone FastAPI recommendation service using TF-IDF, cosine similarity, and weighted behavioral scoring.

**Engineering highlights**

- Nearby-provider discovery using GeoJSON and MongoDB `2dsphere` queries
- One-time meal orders, carts, subscriptions, vacation mode, and order history
- Provider onboarding, FSSAI uploads, weekly menus, wallets, and payouts
- Admin approval, marketplace monitoring, and role-based access control
- Razorpay payments with signature verification and provider earnings flow
- Personalized recommendations through an independently deployable ML service
- Docker-based multi-service deployment architecture

`React` `Redux Toolkit` `Node.js` `Express` `MongoDB` `FastAPI` `Pandas` `scikit-learn` `Razorpay` `Cloudinary` `Docker`
